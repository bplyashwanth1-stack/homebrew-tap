# Homebrew tap

Homebrew formulas for [Cadence](https://github.com/bplyashwanth1-stack/Cadence), synced and animated lyrics on
the Mac lock screen.

```sh
brew install bplyashwanth1-stack/tap/cadence
```

Homebrew builds Cadence on your Mac (Apple silicon, macOS 14 or later), so macOS doesn't show an "unidentified
developer" warning. Follow the one-line instruction it prints to put Cadence in your Applications folder.

Update with `brew upgrade cadence`; remove with `brew uninstall cadence`.
